# Шаблон отчета: 8 блоков

Отчет выдается одним сообщением (файлом). Методологию внутри не пересказывать. Блок без содержимого сворачивается в одну строку «нечего сообщить» (кроме блока 6 — его можно опустить, если пуст). После блока 8 — никакого текста.

---

## Блок 1 — Контекст анализа

- Ниша и тип бизнеса — одна строка.
- Стратегия ставок (определена из данных или подтверждена пользователем).
- Какие срезы проанализированы, за какой период.
- Какие данные отклонены/отложены — по каждому одна строка-пояснение.
- Если не хватило данных о бизнесе — одна строка, чего не хватило.
- Если нет данных о фактических продажах — одна строка: «Данные о реальных сделках за период не получены, оптимизация ведется по конверсиям Google Ads. Пришлите цифры по сделкам в следующий раз».

## Блок 2 — Готовность данных

Короткий список по каждому срезу:
- готов — анализ проведен;
- частично готов — разобраны только доминирующие сегменты;
- данных недостаточно — вернуться через N дней с периодом N дней.

## Блок 3 — Значимые наблюдения

По каждому проанализированному срезу — 1–5 наблюдений, прошедших принципы существенности и сходимости. На каждое:
- какой сегмент;
- какие метрики и как отклонились (от среднего по отчету / от ваших цифр);
- короткая интерпретация (гипотеза или диагноз).

Если значимого ничего нет — одна строка.

## Блок 4 — Кросс-закономерности

Паттерны на пересечении двух и более срезов, прошедшие три фильтра (существенность, усиление, устойчивость):
- пересечение каких дименсий;
- в чем проявилось различие;
- гипотеза о причине.

Если нет — одна строка.

## Блок 5 — Что делать сейчас

**Максимум 2 рекомендации.** По каждой:
- что именно сделать (концептуально, без инструкций по интерфейсу);
- уровень (аккаунт / кампания / группа);
- сошедшиеся сигналы — какие метрики вместе сделали это диагнозом;
- совпавший паттерн из каталога;
- ограничения: правило 20% (с конкретным числом шага, если применимо), учет стратегии ставок;
- ожидание: что должно измениться, если правка сработает.

Если действий нет — одна строка: «В этом цикле действий не требуется. Продолжайте текущие настройки; следующая проверка — по ритму из блока 8».

## Блок 6 — Отложить до следующего цикла

Кандидаты, не попавшие в блок 5 (правило одной переменной, меньший вес). По каждому: что сделать + почему отложено («чтобы не смешивать с основной правкой», «дождаться стабилизации», «меньший денежный вес»). Если пусто — блок можно опустить.

## Блок 7 — Точки внимания

Гипотезы и неустойчивые диагнозы. По каждой: сегмент/пересечение → вырисовывающийся паттерн → что нужно для подтверждения (обычно «еще объем данных» или «повтор в следующем периоде»). Если нет — одна строка.

## Блок 8 — Ритм следующих проверок

По каждому срезу отдельно:
- через сколько дней возвращаться (30 / 60 / 90);
- с каким периодом данных;
- если по срезу назначена правка из блока 5 — пометка «после стабилизации правки, не раньше чем через X дней».
