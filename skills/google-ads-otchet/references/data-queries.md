# Что забирать из кабинета через конектор Google Ads

Данные тянутся автоматически через нативный конектор Google Ads (Beta) — пользователь ничего не выгружает вручную. Период по умолчанию: **последние 30 дней** + предыдущие 30 дней для динамики. Если в кабинете мало данных — расширь период до 60–90 дней и отметь это в отчете.

## Обязательные срезы

1. **Кампании** — показы, клики, CTR, средняя цена клика, расходы, конверсии, стоимость конверсии.
2. **Ключевые слова** — те же метрики + доля полученных показов в поиске, доля потерянных показов из-за бюджета, доля потерянных показов из-за рейтинга.

## Дополнительные срезы (если доступны в конекторе)

3. **Объявления** — базовые метрики.
4. **География** — базовые метрики.
5. **День недели** — базовые метрики.
6. **Час дня** — базовые метрики.
7. **Устройства** — базовые метрики.
8. **Аудитории** — базовые метрики.
9. **Демография** — базовые метрики.

## Правила забора

- Тяни только **поисковые** кампании. Данные Performance Max, Demand Gen, YouTube, Shopping, Discovery — не трогать (протокол покрывает только поиск).
- Стратегию ставок определи из данных: колонка «стратегия» напрямую, иначе по признакам (целевая CPA / целевой ROAS / «максимум конверсий» → авто; заполненный макс. CPC → ручная).
- Если срез недоступен через конектор — работай с тем, что есть, и честно отметь пробел в блоке «Готовность отчетов».
- Не проси пользователя выгружать CSV — весь смысл скилла в том, что данные забираются сами.
