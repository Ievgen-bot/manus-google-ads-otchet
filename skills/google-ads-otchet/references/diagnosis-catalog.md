# Каталог диагностических паттернов

Каждый паттерн: форма отклонений → диагноз → направление действий (для ручных и автоматических стратегий). Подбирайте паттерн только после применения 5 принципов. Не подошедший ни под один паттерн кандидат — наблюдение без назначенного действия.

## PATTERN_01 — Несоответствие объявления сегменту

**Форма:** CTR заметно ниже среднего по отчету + CPC около среднего + конверсии низкие или нулевые + доля расходов существенна.

**Диагноз:** текст объявления не резонирует с этим сегментом — объявление видят, но не кликают.

**Ручные ставки:** значительно снизить ставку или исключить сегмент.
**Автостратегии:** исключить сегмент напрямую; корректировки ставок не применяются.

## PATTERN_02 — Конкурентный перегрев

**Форма:** CTR около среднего + коэффициент клик-в-конверсию около среднего + CPC заметно выше среднего по отчету + CPA выше приемлемого диапазона владельца.

**Диагноз:** аукционное давление в сегменте выталкивает цену клика за пределы экономики, которая работает.

**Ручные ставки:** снизить ставку для сегмента.
**Автостратегии:** исключить сегмент, если несоответствие устойчиво.

## PATTERN_03 — Несоответствие лендинга или оффера

**Форма:** CTR около среднего или выше + коэффициент клик-в-конверсию заметно низкий + доля расходов существенна.

**Диагноз:** объявление приводит клики, но дальнейший опыт (лендинг, оффер, цены) не соответствует обещанию для этого сегмента.

**Действие:** исключить сегмент, чтобы остановить слив. Отметьте, что может потребоваться отдельная проверка сайта (вне рамок этого протокола).

## PATTERN_04 — Чистый слив

**Форма:** ноль конверсий + существенные расходы + остальные метрики около средних.

**Диагноз:** сегмент просто не конвертит при ничем не примечательных верхних метриках.

**Ручные ставки:** сильно снизить ставку или исключить.
**Автостратегии:** исключить.

## PATTERN_05 — Недокачанный лидер

**Форма:** CPA заметно лучше среднего по отчету + объем конверсий низкий + видно запас capacity.

**Диагноз:** рабочий сегмент недополучает показы при текущих настройках.

**Ручные ставки:** умеренно поднять ставку.
**Автостратегии:** усилить сигнал (наблюдение за аудиторией), не пережимать. Если аудитория уже в таргетинге — без действий.

## PATTERN_06 — Большая доля «Неизвестно»

**Форма:** большая доля «Не определено» / Unknown / Unspecified в отчете.

**Диагноз:** измерение по этой дименсии ненадежно — большинство пользователей не попали ни в один именованный сегмент.

**Действие:** не делать сильных выводов по именованным сегментам. Анализировать саму корзину «Неизвестно» как отдельный сегмент — если она существенно недожимает, исключать или корректировать ее напрямую.

## PATTERN_07 — Потолок бюджета

**Форма:** в отчете по ключевым словам заметная доля потерянных показов из-за бюджета.

**Диагноз:** потолок бюджета ограничивает охват.

**Действие:** НЕ назначать масштабирование бюджета внутри этого протокола — это отдельный модуль. Вынести в точки внимания.

## PATTERN_08 — Потолок рейтинга

**Форма:** заметная доля потерянных показов из-за рейтинга + существенные расходы.

**Диагноз:** рейтинга объявления не хватает — комбинация ставки и качественных факторов.

**Ручные ставки:** рассмотреть умеренное повышение ставки с ограничением правилом 20%.
**Автостратегии:** вынести в точки внимания (рейтинг на автостратегиях — производная алгоритма, а не прямой рычаг).

## PATTERN_09 — Резкий внутренний разброс

**Форма:** внутри одного сегмента два подсегмента ведут себя драматически по-разному (один работает, другой сливает).

**Диагноз:** сегмент неоднороден; текущие настройки обращаются с хорошей и плохой частями как с одним целым.

**Действие:** вынести в точки внимания — возможно, стоит разделить на отдельные группы с отдельными объявлениями (реструктуризация — вне рамок протокола).

## PATTERN_10 — Ниже существенности

**Форма:** малая доля расходов и малая доля конверсий — ни явный победитель, ни явный проигравший.

**Диагноз:** шум. Без действий, без упоминания в отчете. Значение по умолчанию для большинства сегментов.
